# GKAuto

吉利GKUI车机自动连接工具，支持蓝牙配对绑定、WiFi连接手机热点、开机自启等功能。

## 功能特性

- **蓝牙连接** - BLE + 经典蓝牙双模式，支持设备绑定和自动重连
- **WiFi热点连接** - 车机自动连接手机热点
- **开机自启** - 开机自动启动GKAuto，连接成功后自动打开绑定应用
- **日志面板** - 实时查看连接日志和设备状态

## 版本要求

- Android 5.1+ (API 22+)
- ROOT权限（用于系统目录操作）

## 使用说明

### 1. 蓝牙绑定
1. 点击「扫描蓝牙」搜索附近设备
2. 选择车机蓝牙设备进行配对
3. 配对成功后点击「绑定设备」

### 2. WiFi热点连接
1. 确保手机已开启热点
2. 点击「扫描WiFi」搜索热点
3. 选择手机热点，输入密码连接

### 3. 绑定应用
1. 在设置中勾选要自动启动的应用
2. 蓝牙连接成功后自动启动该应用

### 4. 开机自启
1. 在设置中开启「开机自启」
2. 车机重启后自动运行GKAuto
