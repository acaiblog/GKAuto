# GKAuto

吉利GKUI车机智能连接工具，自动连接手机热点、开机自启、绑定应用自动启动。

## 功能特性

- **WiFi热点连接** - 车机自动扫描并连接手机热点
- **应用绑定** - 热点连接成功后自动启动指定应用（如高德地图）
- **开机自启** - 车机启动后自动运行GKAuto
- **日志面板** - 实时查看连接状态和操作日志
- **快捷操作** - ADB连接、蓝牙设置、WiFi设置、重启车机

## 版本要求

- Android 5.1+ (API 22+)
- ROOT权限（用于系统目录操作）

## 使用说明

### 1. 连接手机热点
1. 在手机上开启热点
2. 点击「扫描WiFi」搜索热点
3. 选择手机热点，输入密码连接

### 2. 绑定应用
1. 点击「绑定应用」选择要自动启动的应用（如高德地图）
2. 热点连接成功后自动启动该应用

### 3. 开机自启
1. 开启「开机自启」开关
2. 车机重启后自动运行GKAuto
